\# Proyecto Biblioteca Escolar

\- Nombre Apellido (correo)



\## Objetivo

Representar un catálogo de libros con distinta cantidad de ejemplares, ordenarlo

por préstamos con ordenamiento por inserción y localizar libros por ISBN con

búsqueda binaria propia.



\## Estructura de carpetas

\- `Biblioteca escolar-pro/`: solución y código fuente en C#

\- `docs/`: documento de diseño, prueba de escritorio, tabla de comparaciones e informe

\- `README.md`: este archivo

\- `.gitignore`: archivos excluidos del control de versiones



\## Compilación y ejecución

1\. Abrir `Biblioteca escolar-pro.slnx` en Visual Studio.

2\. Compilar con Ctrl+Shift+B.

3\. Ejecutar con F5.
